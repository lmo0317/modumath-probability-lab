മൂന്ന് സംഖ്യകൾ, രണ്ട് ബന്ധങ്ങൾ

ഓരോ ബന്ധത്തിനും യോജിക്കുന്ന ക്രമജോടികൾ ആദ്യം കടലാസിൽ എഴുതുക. പിന്നെ ഉത്തരവുമായി താരതമ്യം ചെയ്യുക.

List the ordered pairs before opening the answer. An arrow from a to b represents the pair (a, b).

1. ഏതാണ് ഹരിക്കുന്നത്? Which number divides which?

A = {1, 2, 4}. b എന്ന സംഖ്യയെ a കൊണ്ട് നിശ്ശേഷം ഹരിക്കാമെങ്കിൽ (a, b) എഴുതുക. ഉദാഹരണം: (2, 4). ബന്ധം പ്രതിസമമാണോ?

Include (a, b) if a divides b exactly. Is every arrow accompanied by an arrow in the opposite direction?

ആറ് ജോടികൾ പരിശോധിക്കുക · Check the six pairs

(1, 1), (1, 2), (1, 4), (2, 2), (2, 4), (4, 4).

Each number divides itself, so the relation is reflexive. It is not symmetric: 2 divides 4, but 4 does not divide 2. It is transitive: whenever a divides b and b divides c, a divides c.

2. ഒരേ ശിഷ്ടം Same remainder

B = {1, 2, 3}. a, b എന്നിവയെ 2 കൊണ്ട് ഹരിക്കുമ്പോൾ ഒരേ ശിഷ്ടം കിട്ടിയാൽ (a, b) എഴുതുക. ഇത്തവണ എല്ലാ അമ്പുകളും തിരിച്ചും വരയ്ക്കാമോ?

Now draw an arrow when the two numbers leave the same remainder on division by 2. Is this an equivalence relation?

ഉത്തരം നോക്കുക · Check your answer

(1, 1), (1, 3), (2, 2), (3, 1), (3, 3).

Yes. A number has the same remainder as itself. If a and b match, b and a match. If a and b match and b and c match, all three have the same remainder. The two classes are {1, 3} and {2}.

3. ഓർമ്മയിൽനിന്ന് ചെയ്യൂ · Try again from memory

Put 4 into set B. Without listing all the pairs, how many arrows have you added?

സൂചനയും ഉത്തരവും · Hint and answer

Before, the two classes had sizes 2 and 1, giving 2² + 1² = 5 pairs. Now both classes have size 2, giving 2² + 2² = 8. The three new arrows are (2, 4), (4, 2) and (4, 4).
