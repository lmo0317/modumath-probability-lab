# Lakh Links

A free, offline-capable number game by ModuMath. Choose four tiles that have the same value. A wrong guess keeps your selection so you can replace a single tile. After you match a set, the game explains its arithmetic. The four sets cover hundreds, thousands, lakhs and crores.

- [Play in Malayalam and English](https://lmo0317.github.io/modumath-probability-lab/lakh-links/ml.html)
- [Play in Hindi and English](https://lmo0317.github.io/modumath-probability-lab/lakh-links/)

To play offline, save either HTML page and open it in a browser. The design uses real buttons, visible keyboard focus, live score announcements and a two-column board on small screens. No accounts, scripts from third parties or local storage are used. The Malayalam page also links to the team's optional English maths practice site.

The standalone game in this directory is [MIT licensed](LICENSE).
